SQL Injection - 데이터 추출
union > select를 한번 더 써서 다른 테이블도 확인이 가능함
union 앞 뒤로 컬럼 수가 맞아야 오류없이 실행이 됨



노말틱님의 sqli 7가지 steps

1. sqli point찾기
특정 단어만 넣어보고 전부 검색이 되는 결과를 보고
 %의 위치와 like를 쓴 쿼리문이라고 생각할 수 있음

2. column 수 파악 (union에서만 적용)
order by Trick
order by는 정렬 해줌 
order by asc는 순서대로 / order by desc는 반대로
order by 1 이렇게 지정한 순서로 검색되어 최대치를 알 수 있음

select 컬럼1, 컬럼2 from 테이블 order by 3
3번째 컬럼 기준으로 정렬이라 오류가 남


3. 출럭 column 확인
select는 유일하게 컬럼이 아니랑 데이터가 들어갈 수 있음
select 엔 date든 숫자가 들어가도 된다


4. Database 이름 확인
select database() 등으로 확인하기 (MySQL 기준)
나오는 칼럼에 써야함


5. table 이름 확인
select table_name from information_schema.tables 등으로 확인하기

칼럼이 많을 경우엔
select 1, table_name, 3, 4 from information_schema.tables
이런 식으로 함

where table_schema = '얻은 데이터베이스 이름'
을 넣으면 해당 데이터베이스의 테이블이름들을 알 수 있음.


6. column 이름 확인
select column_name from information_schema.columns 등으로 확인하기

칼럼이 많을 경우엔
select 1, column_name, 3, 4 from information_schema.columns
이런 식으로 함

where table_schema = '얻은 데이터베이스 이름'

where table_name = '얻은 테이블 이름'
으로 테이블에 있는 컬럼 이름을 알 수 있음
