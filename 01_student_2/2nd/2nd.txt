Burp Suite의 Repeater
Request
Host: 웹 서버 주소
User-Agent: 접속한 유저의 정보(?)
Referer: 요청의 일어난 지점을 알려줌

Respones
서버 상태
2--: 정상
3--: 이동, 리다이렉션 - 로케이션(어디로 가는지)써 있음
4--: 사용자 잘못
5--: 서버 잘못

Server: 서버 정보가 나옴
가릴 순 있지만
에러를 발생시켜 서버 정보를 나오게 할 수 있음
나오는 곳이 좀 있다



Database
table: 저장할 여러 정보들
컬럼: 이름, 아이디, 비밀번호 등 구분해서 저장
행: 저장되어있는 수


DDL - Data Definition Language
CREATE, DROP, ALTER

DCL - Data Control Language
