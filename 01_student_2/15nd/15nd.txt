이미지 파일 실행이 가능한가? (png, jpg)
> 이중 확장자를 이용한 파일 업로드 우회
>> websh.php.jpg
>>> 이건 php 실행이 안됨. 당연히 jpg를 확장자로 인식함
>>> 하지만 (버프스윗에 있는 문제) 이미지를 올릴 수 있는 곳에
이미지를 올리고 url로 접속시 확인이 가능함
>>> 만약 이미지 파일이 아닌 코드파일을 올리면 올라가는 일이 있음
>>>> 파일을 서버에 저장과 파일 확장자 검사의 순서가 바뀌어 저장이 되고 
검사를 하여 저장이 되는 경우도 있음

>>> 버프로 .htaccess 로 이름을 바꾸면 다른 파일로 인식하게 할 수 있음
>>>> AddType application/x-httpd-phg .jpg 라는 내용으로 수정시 
jpg파일을 php파일로 인식하게 할 수 있음

웹 개발시 여러 페이지에 들어가는 부분을 페이지 별로 하드코딩하지 않고
하나의 페이지를 만들고 다른 페이지에 불러오게 하는 기능

그래서 만약 파라미터로 받는다면 ../../../../../../../etc/passwd 같은 파라미터로 패스워드들을 볼 수 있는 취약점이 발생
> 파라미터에 html/main/index/../../../../etc/passwd 는 페이지의 최상디렉토리는 html이라 못올라 가지만 html/main/index?page=../../../../../etc/passwd 이건 php에서 실행이 되는 거라 상위 디렉토리로 올라갈 수 있어서 passwd를 확인 할 수 있음



서버에 있는 아무파일이나 포함시켜서 응답하면 위험한 이유는?
> 민감한 정보를 조회할 수 있음 / env.php 같은 비밀파일이 노출 될 수 있음 / db에 연결되 계정을 확인 할 수 있음 등등
>> 거의 안됨. 실행이 되고 보여주기 때문에


해당 파일을 포함하고 실행하고 보여줌
> 그러니 이미지 파일을 넣으면 실행이 됨
>> <? php system($_GET['cmd']); ?> 가 있는 파일을 업로드 후 이미지 파일 확장자로 수정하고 파라미터에 html/index/upload/test.jpg&cmd=ls 이렇게 하면 ls명령어가 실행이 되어 나옴

- 파일 저장 서버 분리
- 파일 업로드 경로 숨기기
- 저장되는 디렉토리 실행 막기
- 외부 접근 불가능한 디렉토리 이용
