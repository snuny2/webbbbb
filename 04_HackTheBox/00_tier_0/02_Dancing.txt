1. 포트 확인
nmap -sV htb_ip


2. SMB로 폴더 확인
smbclient -L htb_ip -N


3. 폴더 접속
smbclient //htb_ip//WorkShares -N


4. 파일 찾기
ls로 현재 위치파일 확인
cd 폴더 로 위치 이동 및 ls로 파일 확인
flag.txt를 찾아 get 명령어 후 cat 명령어로 flag 확인

1. What does the 3-letter acronym SMB stand for?
세 글자로 된 약어 SMB는 무엇을 의미합니까?

> Server Message Block


2. What port does SMB use to operate at?
SMB는 어떤 포트를 사용하여 작동합니까?

> 445


3. What is the service name for port 445 that came up in our Nmap scan?
Nmap 스캔에서 나타난 445번 포트의 서비스 이름은 무엇입니까?

> microsoft-ds


4. What is the 'flag' or 'switch' that we can use with the smbclient utility to 'list' the available SMB shares on Dancing?
Dancing 시스템에서 사용 가능한 SMB 공유 목록을 표시하기 위해 smbclient 유틸리티와 함께 ​​사용할 수 있는 '플래그' 또는 '스위치'는 무엇입니까?

> -L


5. How many shares are there on Dancing?
댄싱(Dancing)의 주식 수는 몇 주입니까?

> 4


6. What is the name of the share we are able to access in the end with a blank password?
최종적으로 비밀번호 없이 접근할 수 있는 공유 폴더의 이름은 무엇인가요?

> WorkShares


7. What is the command we can use within the SMB shell to download the files we find?
SMB 셸에서 찾은 파일을 다운로드하는 데 사용할 수 있는 명령어는 무엇입니까?

> get
